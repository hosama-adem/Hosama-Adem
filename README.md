### 🚀 Flagship Project: CodeSentinel

**[CodeSentinel Platform](https://github.com/hosama-adem/codesentinel-platform)** is an AI-powered code review system that integrates directly with GitHub via webhooks.
- Uses an **asynchronous FastAPI pipeline** and **Redis** queues to handle pull request payloads without blocking.
- Queries **OpenAI's GPT-4** for deep static analysis and vulnerability scanning.
- Automatically posts actionable, line-level feedback directly onto the PR.
- Managed via a sleek **Next.js dashboard**.
